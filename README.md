# EgyBook — Starter UI
واجهة أولية متجاوبة لتطبيق EgyBook بهوية كحلية ونيون زرقاء/سماوية ولمسات بنفسجية.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في متصفح حديث، أو ارفع المجلد إلى استضافة ثابتة.
3. التفاعلات الحالية تجريبية محليًا: فتح نافذة إنشاء منشور، إضافة منشور للمعاينة، الإعجاب والحفظ والتنقل بين الأقسام.

## ملفات المشروع
- `index.html` هيكل الواجهة باللغة العربية واتجاه RTL.
- `styles.css` الهوية البصرية والتصميم المتجاوب.
- `script.js` التفاعلات التجريبية.

## الخطوة التالية
ربط تسجيل الدخول وقاعدة البيانات ورفع الصور والفيديوهات والرسائل الحقيقية بخدمة خلفية مثل Firebase. هذه النسخة ليست تطبيقًا منشورًا ولا تحتوي على نظام حسابات أو تخزين سحابي حتى الآن.
